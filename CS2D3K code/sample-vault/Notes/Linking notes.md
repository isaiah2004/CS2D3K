# Linking notes

Use `[[Note name]]` to link to a note. Links to notes that don't exist yet, like [[Ideas backlog]], are *unresolved* and will create the note when clicked.

You can link to headings: [[Markdown features#Code blocks]], and give links an alias: [[Welcome|go home]].
